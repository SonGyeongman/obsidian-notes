# 2026-05-10 — 개인 자산 조회 구현

## 개요

inject.js에 개인 자산 데이터 폴링을 추가해 총 자산, 주문 가능 금액, 보유 주식 목록을 주기적으로 수집하도록 구현했다.

---

## 배경

`wts-cert-api.tossinvest.com`은 인증 필요 API로 background.js에서 직접 호출하면 쿠키가 포함되지 않아 401이 발생한다.
inject.js는 페이지 컨텍스트에서 실행되어 `credentials: 'include'`로 `Domain=.tossinvest.com` 세션 쿠키를 자동 포함할 수 있으므로 inject.js가 폴링을 담당한다.

---

## 구현 내용

### pollPersonalData()

`Promise.allSettled`로 3개 API를 동시 호출:

| API | 경로 | 획득 데이터 |
|-----|------|------------|
| GET | `/api/v3/my-assets/summaries/markets/all/overview` | 총 자산 금액 |
| GET | `/api/v1/dashboard/common/cached-orderable-amount` | USD 주문 가능 금액 |
| POST | `/api/v2/dashboard/asset/sections/all` | 보유 주식 상세 |

`Promise.allSettled` 사용으로 하나 실패해도 나머지 결과를 활용.

### 자산 요약 계산

```javascript
const summary = {
  totalAsset:   overviewResult?.total_asset_amount,
  availableCash: orderableResult?.orderableAmountUs?.usd,
  dailyPnL:     calcDailyPnL(holdingsResult),   // 보유 종목 일 손익 합계
  dailyPnLPct:  dailyPnL / (totalAsset - dailyPnL) * 100,
};
```

### buildHoldings() — 보유 주식 파싱

응답 구조:
```
result.sections[type="SORTED_OVERVIEW"].data.products[].items[]
```

각 item에서 추출:
- `ticker`: `stockSymbol` 우선 → `stockCode`
- `avgPrice`, `currentPrice`: USD 우선 → KRW 폴백
- `returnRate`: `profitLossRate.usd × 100` (API는 소수로 반환)

### 폴링 주기

```javascript
setTimeout(pollPersonalData, 5_000);    // 페이지 로드 5초 후 최초 1회
setInterval(pollPersonalData, 60_000);  // 이후 60초 간격
```

## 이벤트 타입

| 이벤트 | 페이로드 | 저장 위치 |
|--------|---------|-----------|
| `TOSS_ASSET_SUMMARY` | `{totalAsset, availableCash, dailyPnL, dailyPnLPct}` | `chrome.storage.local.assetSummary` |
| `TOSS_PORTFOLIO` | `[{ticker, name, qty, avgPrice, currentPrice, returnRate}]` | `chrome.storage.local.portfolio` |

---

## 주의사항

- `profitLossRate`는 소수 (0.091 = 9.1%) → ×100으로 %로 변환 필수
- `parseSectionData()`: 일부 응답에서 `data` 필드가 JSON 문자열로 내려오는 케이스 처리
