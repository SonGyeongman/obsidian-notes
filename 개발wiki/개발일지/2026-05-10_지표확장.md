# 2026-05-10 — 기술 지표 확장

## 개요

기존 MA5/MA20, RSI(14)에서 MACD, 볼린저밴드, MA60/120, RSI(2)를 추가하고, 봇 ON/OFF 토글 스위치를 구현했다.

## 추가된 지표

### MA60 (수급선) / MA120 (경기선)

```javascript
const MA_MID   = 60;   // 수급선
const MA_LONG2 = 120;  // 경기선
```

정배열 판단에 사용: MA5 > MA20 > MA60 > MA120 순서 확인.
`recalcIndicators()`에서 `calcMA(p, 60)`, `calcMA(p, 120)` 추가.

### MACD (12, 26, 9)

```javascript
const MACD_FAST = 12;
const MACD_SLOW = 26;
const MACD_SIG  = 9;
```

최소 34개 가격 데이터 필요. 반환값:

```javascript
{ macd, signal, histogram }
```

히스토그램 양수 증가 = 상승 모멘텀 강화. `calcMACD(prices)` 함수 구현.

### 볼린저밴드 (20일, 2σ)

```javascript
const BB_PERIOD = 20;
const BB_SIGMA  = 2;
```

반환값:

```javascript
{ upper, middle, lower, pctB, bandwidth }
```

`pctB` = (현재가 - 하단) / (상단 - 하단). 0.2 이하면 하단 근접(매수 고려), 1.0 이상이면 상단 이탈(매도 고려).

### RSI(2) — 래리 코너스 단기 반등 전략

```javascript
state.rsi2 = p.length >= 3 ? calcRSI(p, 2) : null;
```

RSI(2) < 5 + 현재가 > MA200 + 현재가 < MA5 조건 충족 시 단기 반등 매수 신호로 활용.

## 봇 ON/OFF 토글

패널 UI의 토글 스위치가 `chrome.storage.local { botEnabled }`를 변경하면 background.js가 즉시 동기화.

```javascript
let _botEnabled = true;
chrome.storage.local.get(['botEnabled'], ({ botEnabled }) => {
  _botEnabled = botEnabled !== false;
});
chrome.storage.onChanged.addListener((changes, area) => {
  if (area === 'local' && 'botEnabled' in changes) {
    _botEnabled = changes.botEnabled.newValue !== false;
  }
});
```

`evaluateSignal()` 진입 시 `_botEnabled === false`이면 즉시 리턴.

## 수급 강세 감지 로직

`handleRankingDataUS()`에서 매수/매도 비율 계산:

```javascript
const ratio = item.sell > 0 ? item.buy / item.sell : null;
if (ratio !== null && ratio >= 2) {
  // 수급 강세 종목 → startTrackingTicker 우선 처리
}
```

ratio ≥ 2.0 (매수가 매도의 2배 이상)을 수급 강세 기준으로 설정.
