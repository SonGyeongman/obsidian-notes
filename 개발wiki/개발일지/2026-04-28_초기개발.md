# 2026-04-28 — 초기 개발

## 개요

토스증권 웹앱에서 동작하는 Chrome MV3 확장 프로그램의 초기 구조를 설계하고 핵심 기능을 구현했다.

---

## 구현 내용

### Chrome MV3 3-레이어 아키텍처 설계

```
inject.js (페이지 컨텍스트)
  → content.js (isolated world)
  → background.js (Service Worker)
```

MV3는 세 컨텍스트가 격리되어 있어 직접 통신 불가. `window.postMessage` → `chrome.runtime.sendMessage` 릴레이 구조를 설계.

### fetch Monkey-Patching 구현

inject.js에서 `window.fetch`를 덮어써 토스증권 API 응답을 가로챈다.
`response.clone()`으로 응답을 복사해 읽고 원본을 웹페이지에 반환 → 토스증권 앱 동작에 영향 없음.
XHR 레거시 호출 대비 `XMLHttpRequest.prototype.open/send`도 패치.

- 골든크로스 감지: `prevMa5 < prevMa20 && ma5 >= ma20`
- RSI 과매도 감지: `rsi <= 30`

### Cold-Start 해결 (`fetchHistoricalChartData`)

신규 종목 추적 시작 시 MA/RSI 계산에 필요한 과거 데이터 부족 문제를 1분봉 REST API 페이지네이션으로 해결. 목표 200개 캔들을 페이지당 397개씩 수집.

### SSE 알림 채널

`sse-message.tossinvest.com/api/v1/wts-notification` 연결.
MV3 Service Worker는 native EventSource 미지원 → fetch + ReadableStream으로 직접 SSE 파싱.

### BM25 RAG 서버 (`rag_server.py`)

FastAPI + rank-bm25. `D:\주식정보\주식투자\wiki` 디렉터리의 마크다운 파일을 인덱싱. 청크 크기 400자, 겹침 60자.

## 확인된 주요 사항

- 토스증권 API는 Go 기본 UA(`Go-http-client/1.1`) 403 차단 → `Mozilla/5.0` UA 필수
- `wts-cert-api` 인증 요청은 `credentials: 'include'`로 세션 쿠키 자동 포함
- SSE는 알림 전용 채널 (가격 데이터 없음) → 가격은 REST 폴링으로 별도 수집
- `background.js`, `inject.js`는 Vite 컴파일 없이 그대로 복사 → JSX/import 사용 불가
