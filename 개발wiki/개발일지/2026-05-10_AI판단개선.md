# 2026-05-10 — AI 판단 개선 (null 펀더멘털 PASS 버그 수정)

## 개요

Qwen2.5:14b가 외부 펀더멘털 데이터(PEG, VIX 등)가 null일 때 골든크로스·RSI 신호에도 불구하고 항상 PASS를 반환하는 버그를 수정했다.

---

## 증상

콘솔 로그:
```
[Agent] NAS0240905004 Qwen 판단: PASS | 비중=0% | 목표=— | 손절=—
  — 외부 펀더멘털 정보가 null로 판단 불가능
[Agent] NAS0240905004 PASS — 외부 펀더멘털 정보가 null로 판단 불가능
```

골든크로스 신호가 감지되었지만 AI가 무조건 PASS를 반환했다.

---

## 원인

시스템 프롬프트 규칙 #5의 표현이 모호했다:

```
변경 전:
"5. 외부 펀더멘털(PEG, ROC 백분위 등) null이면 해당 전략 판단 불가로 표시"
```

Qwen은 "판단 불가로 표시"를 "전체 판단 = PASS"로 해석해 기술적 지표(MA, MACD, RSI, BB)가 명확한 매수 신호임에도 PASS를 반환했다.

---

## 수정

시스템 프롬프트 규칙 #5를 명시적으로 수정:

```
변경 후:
"5. 외부 펀더멘털(PEG, ROC 백분위 등)이 null이면 그 항목만 건너뛰고
   1~4번 기술적 지표만으로 판단한다. null 자체는 PASS 사유가 아니다."
```

핵심 변경 사항:
- **"판단 불가로 표시"** → **"그 항목만 건너뛰고"**
- **null이 PASS 사유가 아님**을 명시

---

## 수정 위치

[background.js:99](../../../주식확장프로그램/src/background.js) — `OLLAMA_TRADER_SYSTEM_PROMPT` 상수의 규칙 #5.

---

## 결과

수정 후 Qwen은 null 펀더멘털을 무시하고 기술적 지표만으로 판단을 수행한다.
골든크로스 + MACD 상향 + RSI 과매도 조건이 충족되면 BUY 결정을 반환한다.

---

## 교훈

LLM 시스템 프롬프트에서 "판단 불가" 같은 모호한 표현은 전체 결과를 PASS/null로 단락시킬 수 있다.
null 데이터 처리 규칙은 **해당 항목만 건너뛰고 나머지는 정상 판단**임을 명시해야 한다.
