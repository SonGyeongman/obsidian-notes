## 이벤트 타입별 페이로드 구조

### `TOSS_RANK_DATA` — 인기 순위 100

**발생 경로**: inject.js `normalizeRankData()` → postMessage → content.js → background.js `handleRankData()`

```javascript
// payload: Array<RankItem>
[
  {
    symbol:     "NAS0240905004",  // 종목 코드 (토스 ISIN 또는 ticker)
    name:       "엔비디아",        // 회사명
    marketCode: "NASDAQ",          // 시장 코드
  },
  // ...100개
]
```

**storage 저장**: content.jsx가 `rankStatus` / `rankList`에 저장 (background.js는 name 저장 + 추적 시작만)

---

### `TOSS_RANKING_DATA_US` — 해외주식 거래대금 랭킹

**발생 경로**: inject.js `normalizeRankingDataUS()` → background.js `handleRankingDataUS()`

```javascript
// payload: Array<SupplyItem>
[
  {
    rank:        1,                // 랭킹 순위
    productCode: "NAS0240905004", // 종목 코드
    name:        "엔비디아",        // 회사명
    price:       135.72,           // 현재가 (price.close)
    buy:         15420,            // 토스 유저 매수 금액
    sell:        3210,             // 토스 유저 매도 금액
  },
  // ...100개
]
```

**storage 저장**: 없음 (StockState.supplyData에만 저장)

### `TOSS_CHART_HISTORY` — 차트 과거 데이터

**발생 경로**: inject.js `normalizeChartHistory()` → background.js `handleChartHistory()`

```javascript
// payload: ChartHistory
{
  ticker: "NAS0240905004",   // result.code (우선) 또는 URL에서 추출
  prices: [120.5, 121.0, ...], // 시간 오름차순 종가 배열 (number[])
}
```

**storage 저장**: 없음 (stockState.prices에 병합)

---

### `TOSS_QUOTES_DATA` — 실시간 시세

**발생 경로**: inject.js (raw 그대로) → background.js `handleQuotesData()`

```javascript
// payload: 단건 또는 배열 — background.js가 내부에서 정규화
// 지원 형태 (우선순위 순):
{ productCode: "NAS0240905004", currentPrice: 135.72 }  // SSE 단건
{ data: { productCode, currentPrice } }                  // 래핑 단건
{ data: [{ productCode, currentPrice }] }                // 배열
[{ productCode, currentPrice }]                          // 최상위 배열
```

**현재가 필드 폴백**: `currentPrice → price → tradePrice → close → last`

### `TOSS_ASSET_SUMMARY` — 개인 자산 요약

**발생 경로**: inject.js `pollPersonalData()` → background.js `handleAssetSummary()`

```javascript
// payload: AssetSummary
{
  totalAsset:   125000,   // 총 자산 (KRW 또는 USD — API 기준)
  availableCash: 1250.50, // USD 주문 가능 금액 (orderableAmountUs.usd)
  dailyPnL:      35.20,   // 일 손익 합계 (USD, inject.js에서 계산)
  dailyPnLPct:   0.028,   // 일 손익률 (소수)
}
```

**storage 저장**: `chrome.storage.local.set({ assetSummary: payload })`

## StockState 타입

`Map<ticker: string, StockState>` 형태의 인메모리 상태. SW 재기동 시 prices만 `chrome.storage.local._stockPrices`에서 복원.

```javascript
/**
 * @typedef {Object} StockState
 * @property {string|null}   name        회사명 (rankData 또는 rankingDataUS 수신 시 저장)
 * @property {number[]}      prices      1분봉 종가 배열 (최대 MAX_PRICE_HIST=250개, 오름차순)
 * @property {number|null}   ma5         단기 이동평균선 (MA5)
 * @property {number|null}   ma20        중기 이동평균선 (MA20)
 * @property {number|null}   ma60        수급선 (MA60)
 * @property {number|null}   ma120       경기선 (MA120)
 * @property {number|null}   prevMa5     직전 틱의 MA5 (골든크로스 감지용)
 * @property {number|null}   prevMa20    직전 틱의 MA20 (골든크로스 감지용)
 * @property {number|null}   rsi         RSI(14) Wilder's SMA
 * @property {number|null}   rsi2        RSI(2) — 래리 코너스 단기 반등 전략용
 * @property {MACDResult|null} macd      MACD 계산 결과
 * @property {BBResult|null}   bb        볼린저밴드 계산 결과
 * @property {number}        lastSignalAt 마지막 신호 타임스탬프 (쿨다운 비교용)
 * @property {SentimentResult|null} sentiment 커뮤니티 여론 분석 결과
 * @property {SupplyData|null}      supplyData 거래대금 랭킹 수급 데이터
 */
```

### MACDResult

```javascript
{
  macd:      number,  // MACD선 (EMA12 - EMA26)
  signal:    number,  // 시그널선 (EMA9 of MACD)
  histogram: number,  // 히스토그램 (macd - signal)
}
```

### BBResult (볼린저밴드)

```javascript
{
  upper:     number,  // 상단 밴드 (mean + 2σ)
  middle:    number,  // 중심선 (MA20)
  lower:     number,  // 하단 밴드 (mean - 2σ)
  pctB:      number,  // %b — 0=하단, 0.5=중심, 1=상단 (<0 하단이탈, >1 상단이탈)
  bandwidth: number,  // 밴드폭 = (upper-lower)/middle
}
```

### SentimentResult

```javascript
{
  sentiment:  '긍정' | '부정' | '관망',
  keywords:   string[],    // 핵심 키워드 3개
  summary:    string,      // 한 줄 요약
  analyzedAt: number,      // Unix timestamp (ms)
}
```

### SupplyData

```javascript
{
  rank:      number,       // 거래대금 랭킹 순위
  name:      string,       // 회사명
  price:     number,       // 거래대금 랭킹 기준 종가 (price.close)
  buy:       number,       // 토스 유저 매수 금액
  sell:      number,       // 토스 유저 매도 금액
  ratio:     number|null,  // buy/sell (sell=0이면 null)
  updatedAt: number,       // Unix timestamp (ms)
}
```

## SignalDetail 타입

`evaluateSignal` → `emitBuySignal`로 전달되는 신호 상세 정보.

```javascript
{
  ticker:       string,       // 종목 코드
  name:         string|null,  // 회사명
  reason:       'GOLDEN_CROSS' | 'RSI_OVERSOLD',
  ma5:          number|null,
  ma20:         number|null,
  rsi:          number|null,
  currentPrice: number|null,
  tradeDecision: TradeDecision|null,  // Qwen2.5 매매 판단 결과
  timestamp:    number,       // Unix timestamp (ms)
}
```

## TradeDecision 타입

`decideTradeWithQwen()`이 반환하는 AI 판단 결과. 가드레일 통과 후 `emitBuySignal`로 전달.

```javascript
{
  decision:             'BUY' | 'PASS' | 'SELL',
  allocation_percent:   number,   // 투입 비중 (소수, 예: 0.1 = 10%)
  expected_return_rate: number,   // JS 직접 계산: (목표가-현재가)/현재가 - 수수료
  actual_loss_rate:     number,   // JS 직접 계산: (손절가-현재가)/현재가 - 수수료 (음수)
  target_price:         number,   // AI가 설정한 목표가 ($)
  stop_loss:            number,   // AI가 설정한 손절가 ($)
  reason:               string,   // 판단 근거 (1줄)
}
```

**SAFE_PASS** (AI 오류 시 반환):

```javascript
{
  decision: "PASS",
  allocation_percent: 0,
  expected_return_rate: 0,
  target_price: 0,
  stop_loss: 0,
  reason: "AI 오류로 인한 시스템 강제 관망",
}
```
