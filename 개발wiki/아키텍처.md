# 아키텍처 — 3-레이어 메시지 흐름

## Chrome MV3 확장 구조

Chrome MV3에서는 세 가지 실행 컨텍스트가 격리되어 있다. 각 레이어는 직접 통신할 수 없으므로 아래 흐름으로 데이터를 전달한다.

```
[토스증권 웹페이지]
  │  window.fetch / XHR (monkey-patched)
  ▼
[inject.js] — 페이지 컨텍스트 (window scope)
  │  window.postMessage({ namespace: "TOSS_INTERCEPTOR", eventType, payload })
  ▼
[content.js] — isolated world (확장 컨텍스트)
  │  chrome.runtime.sendMessage({ type, payload, meta })
  ▼
[background.js] — Service Worker
  │  chrome.storage.local.set(...)  →  팝업 UI 갱신
  │  fetch(ollamaUrl)               →  Qwen2.5 AI 판단
  │  fetch(discordWebhookUrl)       →  Discord 알림
  │  fetch(obsidianApiUrl)          →  Obsidian 저장
  │  fetch(ragServerUrl)            →  위키 RAG 검색
```

## inject.js 동작 원리

### fetch Monkey-Patching
```javascript
const _originalFetch = window.fetch.bind(window);
window.fetch = async function(input, init) {
  const response = await _originalFetch(input, init);
  if (matchRule(url)) {
    const raw = await response.clone().json();  // 원본 응답 보존
    const payload = normalizePayload(eventType, raw, meta);
    if (payload !== null) postIntercepted(eventType, payload, meta);
  }
  return response;  // 페이지에는 원본 그대로 반환
};
```

**핵심**: `response.clone()`으로 응답을 복사해 읽고, 원본은 웹페이지에 그대로 반환 → 토스증권 앱 동작에 영향 없음.

### 개인 데이터 폴링
inject.js는 fetch 인터셉트 외에 **자체 폴링**도 수행한다.
- 페이지 로드 후 5초 뒤 최초 조회
- 이후 60초 주기로 반복
- `credentials: 'include'`로 `wts-cert-api.tossinvest.com` 직접 호출 (Domain=.tossinvest.com 쿠키 자동 포함)

## background.js Service Worker 생명주기

MV3 Service Worker는 약 30초 비활성 후 종료된다. 이를 대비해:

| 문제 | 해결책 |
|------|--------|
| SW 종료 시 stockState 초기화 | `chrome.storage.local`에 prices 배열 스냅샷 저장 |
| SW 슬립 방지 | `chrome.alarms("tossKeepalive")` 24초 주기 알람 |
| SSE 연결 끊김 | keepalive 알람에서 SSE 상태 점검 + 자동 재연결 |
| 가격 폴링 | `chrome.alarms("tossPricePoll")` 30초 주기 REST 폴링 |

```

        │ window.postMessage
        ▼
  content.js (relay)
        │ chrome.runtime.sendMessage
        ▼

        │

        │

```

## 빌드 파이프라인

```
npm run build  →  node build.js
  [1/3] src/content.jsx  →  dist/content.js     (Vite IIFE 컴파일)
  [2/3] src/panel/*.jsx  →  dist/panel/          (Vite ES 모듈)
  [3/3] copyFileSync:
          src/background.js  →  dist/background.js  (복사만, 컴파일 없음)
          src/inject.js      →  dist/inject.js       (복사만, 컴파일 없음)
          manifest.dist.json →  dist/manifest.json
```

> **주의**: `background.js`와 `inject.js`는 **순수 JS** 파일로 Vite 컴파일 없이 그대로 복사된다.
> 따라서 이 파일들에는 JSX, import/export, TypeScript를 사용할 수 없다.
