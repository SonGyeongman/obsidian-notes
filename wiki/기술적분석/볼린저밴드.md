# 볼린저밴드 (Bollinger Bands)

> 관련 지표: [[이동평균선]] | [[MACD]] | [[RSI]] | [[스토캐스틱]] | [[OBV]] | [[TA_Index]]

---

## 1. 계산 로직

### 1-1. 기본 산식

$$\text{중심선} = MA(20)$$

$$\text{상단밴드} = MA(20) + 2\sigma$$

$$\text{하단밴드} = MA(20) - 2\sigma$$

- $\sigma$: 최근 20일 종가의 표준편차
- **기본 파라미터**: 20일, 2σ (표준편차 배수)
- 정규분포 가정 시 가격의 **약 95%**가 밴드 내에 위치

### 1-2. 파생 지표

$$\%b = \frac{\text{종가} - \text{하단밴드}}{\text{상단밴드} - \text{하단밴드}}$$

$$\text{밴드폭(Bandwidth)} = \frac{\text{상단밴드} - \text{하단밴드}}{\text{중심선}}$$

| 지표 | 해석 |
|------|------|
| %b > 1 | 상단밴드 상회 (극단적 과매수) |
| %b = 1 | 상단밴드 터치 |
| %b = 0.5 | 중심선 위치 |
| %b = 0 | 하단밴드 터치 |
| %b < 0 | 하단밴드 하회 (극단적 과매도) |
| 밴드폭 작음 | 변동성 수축 (스퀴즈 임박) |
| 밴드폭 큼 | 변동성 확대 |

---

## 2. 매수 트리거

| 신호 유형 | 조건 |
|-----------|------|
| **하단밴드 반등** | 주가가 하단밴드를 터치/이탈 후 **밴드 내부로 복귀하며 양봉** 마감 |
| **스퀴즈 후 상단 돌파** | 밴드폭이 극도로 좁아진 후(스퀴즈) 주가가 **상단밴드 위로 돌파** |
| **중심선(20MA) 지지 반등** | 상승 추세 중 주가가 중심선에 닿고 반등 (지지선 역할) |
| **Walking the Band** | 강한 상승 추세에서 주가가 상단밴드를 따라 계속 움직임 → 포지션 유지 |

---

## 3. 매도 트리거

| 신호 유형 | 조건 |
|-----------|------|
| **상단밴드 반락** | 주가가 상단밴드를 터치/이탈 후 **밴드 내부로 복귀하며 음봉** 마감 |
| **스퀴즈 후 하단 돌파** | 밴드폭이 극도로 좁아진 후 주가가 **하단밴드 아래로 돌파** |
| **중심선(20MA) 저항** | 하락 추세 중 주가가 중심선에 닿고 하락 (저항선 역할) |
| **Walking the Band 종료** | 상단밴드를 따라가던 주가가 밴드 내부로 이탈 → 청산 고려 |

---

## 4. 한계점 및 주의사항

- **보조 지표**: 볼린저밴드 단독으로는 방향성 판단 불가 → 반드시 추세/모멘텀 지표([[RSI]], [[MACD]])와 병행
- **밴드 터치 ≠ 즉시 반전**: 강한 추세에서 주가가 밴드를 따라 이동(Walking the Band) 가능
- **스퀴즈 방향 불확실**: 스퀴즈 후 상방/하방 모두 가능 → 방향 확인 없이 진입 위험
- **표준편차 가정 한계**: 주가 수익률이 정규분포를 완벽히 따르지 않아 극단값 과소추정 가능
- **기업 분석 병행 필수**: 기술적 신호만으로는 부족 → 기업 경영지표, 실적, 섹터 흐름 함께 분석 필요

## 5. 실전 활용 전략

### 스퀴즈 돌파 전략
```
조건 1: 밴드폭이 최근 6개월 중 최저 수준 (스퀴즈 상태)
조건 2: 볼륨 증가 확인 ([[OBV]] 상승)
조건 3: 상단밴드 돌파 시 매수, 하단밴드 돌파 시 공매도
손절: 돌파 반대 방향의 밴드
```

### W자 바닥 패턴 (존 볼린저 제시)
```
1차 저점: 하단밴드 이하로 하락
조정: 중심선 근처까지 반등
2차 저점: 하단밴드 근처에서 지지 (1차 저점보다 높음)
확인: RSI 상승 다이버전스 동반 시 매수
```
